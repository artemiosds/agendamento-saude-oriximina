Painel MP3 local — isolated speech synthesis program

The MP3 worker is a separate program communicating only through postMessage.
It has no access to the application's database or authenticated client and
does not send call text to any speech provider. Audio is generated in memory.

Worker/PCM source (GPL-3.0-or-later):
  /painel-audio/painelMp3.worker.ts
  /painel-audio/painelMp3Encoding.ts
Build command in this project's source: npm run build:panel-audio
Build recipe: scripts/build-panel-audio.mjs
