# Contexto de origem da auditoria
- A função GET /api/audit-origin usa apenas a própria requisição na infraestrutura Vercel. Não aceita IP de terceiros como parâmetro, não consulta o banco e não envia registros clínicos.
- O IP e município/UF/país estimados são capturados quando o serviço compartilhado auditService registra um evento de usuário interno identificado. O contexto é salvo no JSON detalhes.contexto_rede já existente; não há migration. A rotina independente de autenticação também captura o contexto nos logins e logouts de usuários internos identificados. Outros produtores de logs permanecem inalterados.
- Cache por até 5 minutos, consulta concorrente compartilhada, fallback IP-only com retry limitado. A captura total usa timeouts de 1100 ms e 650 ms para o fallback (o fluxo normal de IP continua limitado a 1500 ms; a captura adicional tem orçamento de até 1750 ms em caso de fallback).
- A função só opera quando VERCEL=1 e há um único IP válido no cabeçalho x-vercel-forwarded-for. A prévia exata do projeto Lovable consulta a API de produção por HTTPS, com CORS restrito à origem cadastrada, sem cookies ou credenciais. Demais hosts sem função mantêm IP-only. O cabeçalho alternativo x-real-ip só é usado na ausência do principal e no ambiente Vercel. Verificar a configuração real de proxy na homologação.
- Configuração opcional **server-only** AUDIT_INSTITUTIONAL_NETWORKS: objeto JSON com IPs públicos exatos e nomes das redes institucionais, definidos pelo TI autorizado. Não usar prefixo VITE_, não inserir IPs reais no GitHub. Exemplo fictício: {"203.0.113.10":"Rede demonstrativa"}. Não há cadastro ativo fornecido neste commit. Não confundir IP compartilhado com presença física.
- Nenhum GPS, endereço residencial, CEP, coordenadas, identificação de VPN, ISP ou consulta de IP histórico. A localização não é evidência de presença; o contexto é recebido pelo cliente e persistido por ele, não uma atestação inviolável do servidor.
- GeoLite2/MaxMind não está ativado: requer conta, licença, banco atualizado e processo de distribuição/atualização autorizado. A fonte inicial é a GeoIP já disponibilizada pela Vercel. Não enviar IPs históricos a serviços externos sem autorização.
- Antes de uso operacional: confirmar endpoint, captura em contas internas de teste, RLS vigente, minimização e retenção de dados, validação do encarregado LGPD e correspondências fornecidas pelo TI. Não testar gravando eventos reais de pacientes.
